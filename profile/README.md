# EventEase

*Access Made Personal, Participation Made Possible*

</div>

EventEase is an inclusive platform that helps people with mobility access needs, such as wheelchair users, crutch users, seniors, pregnant people, and stroller users, make confident, informed decisions about attending public events.

Generic labels like "Accessible" or "Not Accessible" leave out what matters: whether there is a step-free entrance, an accessible restroom, or a short walk from the drop-off point. EventEase compares each person's needs with what the organizer claims, records the organizer's commitment before the event, and checks it against real experience afterward.

## How It Works

Need, Match, Commit, Verify, Improve.

1. **Need:** attendees describe what they need through a simple checklist, with no medical labels.
2. **Match:** each event gets a personal 0-100 score with a breakdown per accessibility attribute.
3. **Commit:** attendees send an accessibility request and the organizer answers in writing.
4. **Verify:** after the event, attendees confirm whether each promise was kept.
5. **Improve:** verifications update the organizer's reliability score for the next attendee.
